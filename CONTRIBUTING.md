# Guía para Contribuir

Gracias por tu interés en contribuir a este proyecto.

## Flujo de trabajo

1. Crea una rama desde `main` siguiendo la convención: `feature/descripcion`, `fix/descripcion` o `docs/descripcion`.
2. Haz tus cambios y commits siguiendo [Conventional Commits](https://www.conventionalcommits.org/).
3. Crea un Pull Request hacia `main`.
4. Espera la revisión de un CODEOWNER.

## Convenciones

### Mensajes de commit

Usa el formato `tipo: descripción breve`:

```
feat: agregar nueva funcionalidad
fix: corregir error en el cálculo
docs: actualizar documentación
chore: tareas de mantenimiento
```

### Código

- Sigue las convenciones del lenguaje del proyecto.
- Agrega tests para funcionalidad nueva.
- No subas secretos, credenciales ni datos sensibles.

## Reportar problemas

Usa las plantillas de Issues disponibles en el repositorio para reportar bugs o solicitar funcionalidades.
